# bazi-accurate · 精准四柱八字排盘 Skill

> 基于 lunar-python 历法库精确排盘的四柱八字命理分析 Skill，彻底杜绝手工推算日柱、时柱的常见错误。

## 核心特色

- **排盘绝对准确**：使用 [lunar-python](https://github.com/6tail/lunar-python) 历法库脚本计算四柱，自动处理立春分界、节气分界、夜子时等所有易错点，杜绝手工推算日柱时柱的偏差。
- **专业典籍分析**：参照《穷通宝典》《三命通会》《滴天髓》《渊海子平》《千里命稿》《协纪辨方书》《果老星宗》《子平真诠》《神峰通考》九本经典典籍进行专业论命。
- **输出格式规范**：完整输出四柱表（含十神/藏干/纳音）、五行力量分析、大运排列、流年分析、历史事件校准、综合建议。

## 为什么需要这个 Skill？

传统八字排盘依赖手工推算日柱，而日柱计算依赖精确的历法数据（儒略日、节气、闰月等），极易出错。

**已知教训**：手工推算日柱曾出现偏移 10 位的错误，导致时柱连锁错误（日干一变，五鼠遁元起时全错）。

本 Skill 强制要求排盘时运行 `scripts/paipan.py` 脚本，以 lunar-python 历法库的输出为准，确保四柱绝对准确。

## 使用方法

### 排盘脚本

```bash
# 按小时排盘（自动换算时辰）
python3 scripts/paipan.py --solar 1990-05-15 --hour 14 --gender female

# 按时辰名排盘
python3 scripts/paipan.py --solar 1988-10-01 --shichen 子 --gender male
```

**参数说明**：

| 参数 | 必填 | 说明 |
|------|------|------|
| `--solar` | 是 | 阳历日期，格式 `YYYY-MM-DD` |
| `--hour` | 二选一 | 出生小时（0-23），自动换算时辰 |
| `--shichen` | 二选一 | 时辰名（子丑寅卯辰巳午未申酉戌亥） |
| `--gender` | 是 | 性别 `male`/`female` 或 `男`/`女`（影响大运顺逆） |

## 排盘原理

1. **年柱**：以立春为分界（非农历正月初一），立春前出生归上一年。
2. **月柱**：以节气为分界（非农历月份），每月一节（立春→寅月，惊蛰→卯月……）。
3. **日柱**：由 lunar-python 历法库根据儒略日精确计算，杜绝手工推算误差。
4. **时柱**：根据出生时间确定时辰地支，再按日上起时法（五鼠遁元）确定天干。
5. **大运**：阳年男/阴年女顺排，阴年男/阳年女逆排；起运年龄 = 出生日到最近节气天数 ÷ 3。

## 分析框架

Skill 按以下框架输出完整命理分析：

1. 基本信息确认
2. 四柱排盘（天干/地支/十神/藏干/纳音）
3. 五行力量分析
4. 大运排列
5. 综合分析（日主旺衰、调候用神、格局判定、十神性格、大运分析、流年分析）
6. 历史事件校准（预测已发生事件让用户验证）
7. 综合建议（事业、财运、婚姻、健康、吉祥方位颜色）
